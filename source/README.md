# Source

Edit `app.js` for application behavior and `shell.html` for interface and styles. Run `python3 source/build.py` from the repository root to regenerate `index.html`.

The app has no runtime dependencies. Browser tests live in `tests/`; see the root README for setup. Test data must be synthetic and generated at runtime. Do not add research datasets, local exports, credentials or machine-specific paths to the repository.
