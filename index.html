How to annotate and save

Open a folder: select a supported archive with Open dataset ZIP, or choose its extracted folder. Manifest-based and paired JSON collections are supported. Existing deceptions and visual perceptions load beside their matching image. Visual perceptions remain neutral observations. Green answer hints are clues that lead to the correct answer. Use the entry type dropdown to explicitly turn an observation into an answer hint. Use Previous, Next or the image list to browse. Switching images keeps your edits.

Masks: click + Evidence mask, then draw an opaque violet rectangle over evidence to hide it. You can draw several masks, move, resize or delete them. Download masked PNG bakes masks into a separate image, without labels or other boxes. Dataset downloads include every image with boxes and masks applied, plus retained originals for editable reopening.
Edit: change text directly, add or delete entries, and select an entry before drawing boxes. Each text can have multiple boxes. In Select / move mode, drag a box to move it or drag its bottom-right handle to resize. The controls below the image edit coordinates and the linked text. Delete removes the selected box; Escape cancels the current drag. Undo restores up to 40 recent operations.

Image download: Download annotated PNG saves the current image at original resolution with all hint, deception and observation boxes, and violet masks. Selection handles are omitted.
Three outputs: Download dataset variants saves one ZIP containing hints_only (green hint outlines), deceptions_only (red deception outlines) and deceptions_masked (violet masks over the same deception boxes). All images are included. Observations and manually drawn evidence masks are excluded from these isolated variants. The variant selector can download one dataset instead. Reopening the combined ZIP loads hints_only and restores the entire annotation session; you can also extract and open any individual variant folder.
Save: Download revised dataset creates a ZIP with the original metadata, updated texts, editable geometry and all images with boxes and masks applied. Clean originals are retained inside the package so overlays do not accumulate when you reopen and export again. Extract that ZIP into a folder and open it to continue. The browser downloads a revised copy; it does not overwrite the original folder. Save before closing or reopening a collection. There is no automatic disk save.

Other inputs: a folder containing only images starts blank entries. Add images also accepts individual files. Download JSON saves these collections with embedded images; Import JSON reopens them. PNG, JPEG, WebP and GIF are supported. Use a still frame for animated images.
